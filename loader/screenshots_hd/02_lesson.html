Introduction to Logic
Logic is the study of reasoning and argumentation. It helps us distinguish valid arguments from invalid ones. A valid argument is one where the conclusion follows logically from the premises.

💡 Key Point: Logic is about HOW we think, not WHAT we think. It provides tools for evaluating arguments.

In everyday life, we use logic when we make decisions, solve problems, and evaluate claims. Critical thinking is the practical application of logical principles.
📌 Cheat Notes

Argument = Premises + Conclusion. Valid argument = Conclusion follows from premises. Sound argument = Valid + True premises.
