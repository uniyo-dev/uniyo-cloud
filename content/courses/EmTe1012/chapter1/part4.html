What is Human-Machine Interaction (HMI)?

Human-machine interaction (HMI) refers to the communication and interaction between a human and a machine via a user interface. The user interface is the "bridge" that allows the human to give commands to the machine and allows the machine to display feedback to the human. In the past, this meant physical buttons, switches, and knobs. Today, HMI has evolved dramatically.

Natural User Interfaces: Nowadays, natural user interfaces such as gestures (swiping, pinching, waving), voice commands, and even eye tracking have gained increasing attention. These allow humans to control machines through natural and intuitive behaviors—behaviors that feel as natural as talking to another person or pointing at an object. For example, you don't need to learn complex code to use a smartphone; you simply swipe your finger across the screen.

What is interaction in human-computer interaction?

HCI (human-computer interaction) is the study of how people interact with computers and to what extent computers are—or are not—developed for successful interaction with human beings. It is a multidisciplinary field that combines psychology, design, and computer science.

🔑 Key Concept:

As its name implies, HCI consists of three parts:

  1. The user (the human being interacting with the system).
  2. The computer itself (the hardware and software system).
  3. The ways they work together (the interface, the interaction methods, and the usability).
Component of HCIDescriptionExample
The User The human individual who has goals, needs, and limitations (cognitive, physical, emotional). A farmer in rural Ethiopia using a mobile app to check crop prices.
The Computer The hardware (screen, keyboard, processor) and software (operating system, applications) that the user interacts with. The smartphone itself, the TeleBirr app, and the Ethio Telecom network.
The Interaction The interface and the methods by which the user controls the computer and receives feedback. Swiping the screen, typing a password, viewing a confirmation message.

How do users interact with computers?

Hardware Level: The user interacts directly with hardware for human input and output. This includes:

  • Input Hardware: Devices that allow the user to give commands to the computer (keyboard, mouse, touchscreen, microphone, camera).
  • Output Hardware: Devices that display information back to the user (monitor/screen, speakers, printer, haptic feedback).

Software Level: The user interacts with the computer over a software interface—most commonly a Graphical User Interface (GUI). A GUI uses icons, menus, buttons, and visual metaphors to make the computer easier to use. Instead of typing complex text commands (like in the old DOS days), the user simply clicks on a "File" menu and selects "Save." The GUI translates this action into the underlying code that the computer understands.

💡 Real World Example (Ethiopia - TeleBirr App):

When a user opens the TeleBirr app on their smartphone:

  • Input: They use the touchscreen (hardware) to tap on the "Send Money" button and type the recipient's phone number using the on-screen keyboard (GUI).
  • Processing: The computer (the phone's microprocessor and the TeleBirr server) processes the request.
  • Output: The screen (hardware) displays a confirmation message and the updated balance (GUI).

This seamless interaction is the result of good HCI design.

How important is human-computer interaction?

The goal of HCI is to improve the interaction between users and computers by making computers more user-friendly and receptive to the user's needs. A poorly designed interface can lead to frustration, errors, and wasted time. A well-designed interface can boost productivity, reduce training costs, and improve user satisfaction.

✅ Main Advantages of HCI (From Module):
  • Simplicity: The interface should be easy to understand and use, even for beginners.
  • Ease of deployment & operations: The system should be easy to install, configure, and maintain.
  • Cost savings for smaller set-ups: Good HCI reduces the need for extensive employee training and technical support, saving money.
  • Reduced solution design time: A well-defined interaction model speeds up the development process.
  • Reduced integration complexity: Good interfaces make it easier to connect different systems and components.

1.4.1 Disciplines Contributing to Human-Computer Interaction (HCI)

HCI is not a single field; it is a multidisciplinary field that draws knowledge from many different areas. The module lists six key disciplines that contribute to HCI:

DisciplineContribution to HCIEthiopian Example
Cognitive Psychology Studies human limitations, information processing, performance prediction, cooperative working, and human capabilities. It helps designers understand how the human brain perceives, learns, and remembers information. When designing an app for Ethiopian farmers, cognitive psychologists study how farmers remember information (e.g., using icon-based menus rather than text-only menus, as some users may have low literacy).
Computer Science Provides the technical foundation: computer graphics, underlying technology, prototyping tools, and user interface management systems (UIMS). Ethiopian tech startups at iCog Labs use computer science to build the actual software code that powers AI and HCI interfaces.
Linguistics Helps in the design of natural language processing (NLP), voice user interfaces, and language-based interactions. It ensures that the computer understands human language. Developing voice assistants that can understand Amharic or Oromo requires linguists to map the grammar and syntax of these languages into computer-readable formats.
Engineering and Design Focuses on the physical and visual aspects of the interface. It involves industrial design, ergonomics, and visual design to ensure the hardware is comfortable and the interface is aesthetically pleasing. Designing a solar-powered digital kiosk for rural Ethiopian schools that is durable, easy to maintain, and has a large, readable screen for students.
Artificial Intelligence (AI) AI contributes to creating intelligent interfaces that can adapt to the user's behavior, predict user intent, and provide personalized experiences (e.g., recommendation systems). AI algorithms used in TeleBirr to analyze transaction patterns and detect fraud automatically, or to recommend financial products based on user spending habits.
Human Factors Focuses on the ergonomics and safety of the human-machine system. It studies how physical factors (screen brightness, button size, seating position) affect user performance and health. Ensuring that call center operators at Ethio Telecom have comfortable headsets and monitors that reduce eye strain, improving their long-term productivity.

📌 Cheat Notes: Key Points to Remember (Part 4)

  • HMI: Communication between human and machine via a user interface. Natural interfaces (gestures, voice) are becoming common.
  • HCI: The study of how people interact with computers.
  • 3 Parts of HCI: The User, The Computer, and The Interaction (the interface).
  • How Users Interact: Through hardware (I/O devices) and software (GUI - Graphical User Interface).
  • Goals of HCI: Make computers user-friendly, simple, cost-effective, and easy to integrate.
