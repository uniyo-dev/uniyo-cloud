Why Data Types Matter:

Data types can be described from diverse perspectives. In computer science and computer programming, for instance, a data type is simply an attribute of data that tells the compiler or interpreter how the programmer intends to use the data. This defines what operations can be performed on the data, the meaning of the data, and the way values of that type can be stored.

2.3.1. Data types from Computer programming perspective

Almost all programming languages explicitly include the notion of data type, though different languages may use different terminology. The module lists the following common data types:

Data TypeAbbreviationDescriptionExample
Integer int Used to store whole numbers, mathematically known as integers. They do not have decimal points. 5, 100, -25, 0
Boolean bool Used to represent restricted to one of two values: true or false. This is the basis of all logical operations. True, False
Character char Used to store a single character from the alphabet, a digit, or a special symbol. 'A', 'b', '7', '$'
Floating-point number float Used to store real numbers—numbers that have decimal points. These are essential for scientific and financial calculations. 3.14, 0.005, 1250.75
Alphanumeric string string Used to store a combination of characters and numbers. This is used for text, names, addresses, and sentences. "Hello World", "TeleBirr", "Ethiopia"

💡 Real World Example (Ethiopia - TeleBirr App Code):

When a developer at TeleBirr writes code to handle a money transfer:

  • int: The user ID (e.g., 251912345678) is stored as an integer.
  • float: The amount of money to send (e.g., 150.50 Birr) is stored as a float.
  • string: The recipient's name (e.g., "Almaz Worku") is stored as a string.
  • bool: A variable like `isTransactionSuccessful` is set to `True` if the transfer goes through, or `False` if it fails.

From a data analytics point of view, it is important to understand that there are three common types of data types: Structured, Semi-structured, and Unstructured data types. The diagram below (Figure 2.2 in the module) describes these three types and metadata.

Structured Data

Structured data is data that adheres to a pre-defined data model and is therefore straightforward to analyze. Structured data conforms to a tabular format with a relationship between the different rows and columns. This means the data is highly organized and predictable.

  • Common examples: Excel files, SQL databases, CSV files. Each of these has structured rows and columns that can be sorted and queried.
  • Used by: Traditional relational databases (RDBMS) like MySQL, Oracle, PostgreSQL.

Semi-structured Data

Semi-structured data is a form of structured data that does not conform to the formal structure of data models associated with relational databases or other forms of data tables, but nonetheless, contains tags or other markers to separate semantic elements and enforce hierarchies of records and fields within the data. Therefore, it is also known as a self-describing structure.

  • Common examples: JSON (JavaScript Object Notation), XML (eXtensible Markup Language), HTML, email headers.
  • Used by: NoSQL databases, web APIs, data interchange between systems.

Unstructured Data

Unstructured data is information that either does not have a pre-defined data model or is not organized in a pre-defined manner. Unstructured information is typically text-heavy but may contain data such as dates, numbers, and facts as well. This results in irregularities and ambiguities that make it difficult to understand using traditional programs as compared to data stored in structured databases.

  • Common examples: Audio files, video files, images, No-SQL databases, PDFs, Word documents, emails, social media posts.
  • Used by: Big Data platforms (like Hadoop), data lakes, AI and Machine Learning models.

Metadata – Data about Data

The last category of data type is metadata. From a technical point of view, this is not a separate data structure, but it is one of the most important elements for Big Data analysis and big data solutions. Metadata is data about data.

  • Why is it important? It provides additional information about a specific set of data. For example, in a set of photographs, metadata could describe where and when the photos were taken.
  • Metadata as Structured Data: The metadata then provides fields for dates and locations which, by themselves, can be considered structured data.
  • Usage in Big Data: Because of this reason, metadata is frequently used by Big Data solutions for initial analysis—to quickly understand what data is available before diving into deep processing.

💡 Real World Example (Ethiopia - Agricultural Data):

  • Structured Data: An Excel spreadsheet containing the names of farmers, their plot sizes in hectares, and the crop yields in quintals. This data is ready for analysis.
  • Semi-structured Data: A JSON file sent from a weather station in Oromia containing temperature, humidity, and rainfall data. It has tags (e.g., {"temp": 25, "humidity": 60}) but is not in a table.
  • Unstructured Data: A video recording from a drone flying over a farm in Amhara to inspect crop health. This video cannot be easily searched or analyzed without specialized computer vision algorithms.
  • Metadata: The filename of the drone video ("Amhara_Farm_Drone_2026-08-18.mp4") contains the date and location. This metadata allows the data scientist to quickly find all videos from Amhara without watching them all.

📌 Cheat Notes: Key Points to Remember (Part 2)

  • Programming Data Types: int, bool, char, float, string. These define how the computer stores and processes data.
  • Analytics Data Types: Structured (tables), Semi-structured (tags), Unstructured (text/video/audio).
  • Metadata: "Data about data" – provides context (e.g., date, location, author).
  • Big Data Reality: Most real-world data is unstructured (80%+) – which is why Big Data tools (like Hadoop) are essential.
