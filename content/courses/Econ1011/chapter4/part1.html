4.1 Theory of Production in the Short Run

4.1.1 Definition of Production

Production is the process of transforming INPUTS (factors of production) into OUTPUTS (goods and services). It involves combining land, labor, capital, and entrepreneurship to create something of value.

Key Definition: Production is the transformation of resources (inputs) into goods and services (outputs) that satisfy human wants.

Short Run vs Long Run:

  • Short Run: At least ONE input is FIXED (usually capital/machinery)
  • Long Run: ALL inputs are VARIABLE

💡 Example:

A bakery has a fixed oven (capital) in the short run. It can only vary labor (number of workers). In the long run, it can buy MORE ovens, expand the building, and change ALL inputs.

4.1.2 Production Function

A production function shows the TECHNICAL relationship between inputs and output. It tells us the MAXIMUM output that can be produced with given inputs and technology.

Production Function Formula:
Q = f(L, K)

Where:
Q = Quantity of output
L = Labor (variable input)
K = Capital (fixed input in short run)

4.1.4 The Law of Variable Proportions

The Law of Variable Proportions (also called Law of Diminishing Returns) states that as more units of a VARIABLE input are added to a FIXED input, the marginal product will EVENTUALLY decline.

Law of Variable Proportions: As more units of a variable input (labor) are added to fixed inputs (capital), beyond a certain point, the marginal product of the variable input will eventually DECREASE.

4.1.5 Stages of Production

Stage Characteristics Rationality
Stage I MP is increasing, AP is increasing, TP increasing fast ✅ Underutilization — should add more workers
Stage II MP is decreasing but positive, AP decreasing, TP increasing slowly ✅ RATIONAL — optimal production zone
Stage III MP is NEGATIVE, TP decreasing ❌ Overcrowding — too many workers

📌 Key Points to Remember:

  • Production = Inputs → Outputs
  • Short run = one fixed input | Long run = all variable
  • TP = Total output | AP = TP/L | MP = ΔTP/ΔL
  • Law of Variable Proportions: MP eventually declines
  • Stage II is the RATIONAL production zone
