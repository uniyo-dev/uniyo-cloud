1.3. Argument and Validity

📌 Definition 1.7:

An argument (or logical deduction) is an assertion that a given set of statements \(p_1, p_2, p_3, \ldots, p_n\), called hypotheses or premises, yield another statement \(Q\), called the conclusion.

Example 1.19: Consider the following argument: If you study hard, then you will pass the exam. You did not pass the exam. Therefore, you did not study hard.

Let \(p\): You study hard. \(q\): You will pass the exam. The argument form can be written as:

\(p \Rightarrow q, \neg q \vdash \neg p\)

When is an Argument Valid?

In normal usage, we use an argument in order to demonstrate that a certain conclusion follows from known premises. Therefore, we shall require that under any assignment of truth values to the statements appearing, if the premises became all true, then the conclusion must also become true.

📌 Definition 1.8:

An argument form \(p_1, p_2, p_3, \dots, p_n \vdash Q\) is said to be valid if \(Q\) is true whenever all the premises \(p_1, p_2, p_3, \dots, p_n\) are true; otherwise, it is invalid.

Example 1.20: Investigate the validity of the following arguments:

a. \(p \Rightarrow q, \neg q \vdash \neg p\)

The premises \(p \Rightarrow q\) and \(\neg q\) are true simultaneously in row 4 only. Since in this case \(\neg p\) is also true, the argument is valid.

b. \(p \Rightarrow q, \neg q \Rightarrow r \vdash p\)

Using the truth table, rows 5, 6, and 7 are those in which all premises take value T. In rows 5, 6, and 7, however, the conclusion p takes value F. Hence, the argument form is invalid.

c. Let \(p\): It rains. \(q\): Crops are good. The argument form is \(p \Rightarrow q, \neg p \vdash \neg q\).

The premises \(p \Rightarrow q\) and \(\neg p\) are true simultaneously in row 4 only. Since in this case \(\neg q\) is also true, the argument is valid.

📌 Important Remarks:
  1. What is important in validity is the form of the argument rather than the meaning or content of the statements involved.
  2. The argument form \(p_1, p_2, p_3, \ldots, p_n \vdash Q\) is valid iff the statement \((p_1 \land p_2 \land p_3 \land \ldots \land p_n) \Rightarrow Q\) is a tautology.

Rules of Inferences

Below we list certain valid deductions called rules of inferences.

Formal Proof of Validity of an Argument

📌 Definition 1.9:

A formal proof of a conclusion \(Q\) given hypotheses \(p_1, p_2, p_3, \dots, p_n\) is a sequence of statements, each of which applies some inference rule to hypotheses or previously proven statements (antecedent) to yield a new true statement (the consequent).

Example 1.22: Show that the hypotheses "It is not sunny this afternoon and it is colder than yesterday. If we go swimming, then it is sunny. If we do not go swimming, then we will take a canoe trip. If we take a canoe trip, then we will be home by sunset." lead to the conclusion "We will be home by sunset."

Let \(p\): It is sunny this afternoon. \(q\): It is colder than yesterday. \(r\): We go swimming. \(s\): We take a canoe trip. \(t\): We will be home by sunset.

4\(\neg r\)Modus Tollens using (2) and (3)

📌 Cheat Notes: Key Points to Remember (Part 5)

  • Argument: Premises \(\vdash\) Conclusion.
  • Validity Test: If all premises are T, conclusion must be T. Otherwise, invalid.
  • Key Equivalence: An argument is valid iff \((p_1 \land p_2 \land \dots \land p_n) \Rightarrow Q\) is a tautology.
  • 10 Rules of Inference: Modus Ponens, Modus Tollens, Syllogism, Adjunction, Detachment, Tollendo Ponens, Ponendo Tollens, Constructive Dilemma, Equivalence, Conditionalization.
  • Formal Proof: A step-by-step sequence applying inference rules to reach the conclusion.
