Chapter 1: Propositional Logic and Set Theory

Part 4: Open Propositions & Quantifiers

📖 MODULE OVERVIEW & LEARNING OBJECTIVES:

In mathematics, one frequently comes across sentences that involve a variable. For example, $x^2 + 2x - 3 = 0$ is one such. The truth value of this statement depends on the value we assign for the variable $x$. In this part, we study these open propositions and how they can be converted into propositions using quantifiers.

After completing this part, you will be able to:

  • Define open proposition (predicate).
  • Analyze the difference between a proposition and an open proposition.
  • Differentiate the two types of quantifiers.
  • Convert open propositions into propositions using quantifiers.
  • Determine the truth value of a quantified proposition.

1.2. Open propositions and quantifiers

📌 Definition 1.4:

An open statement (also called a predicate) is a sentence that contains one or more variables and whose truth value depends on the values assigned for the variables. We represent an open statement by a capital letter followed by the variable(s) in parentheses, e.g., $P(x), Q(x)$, etc.

Example 1.11: Here are some open propositions:

  • a. $x$ is the day before Sunday.
  • b. $y$ is a city in Africa.
  • c. $x$ is greater than $y$.
  • d. $x + 4 = -9$.

It is clear that each one of these examples involves variables but is not a proposition as we cannot assign a truth value to it. However, if individuals are substituted for the variables, then each one of them is a proposition or statement. For example, we may have the following:

  • a. Monday is the day before Sunday. (T)
  • b. London is a city in Africa. (F)
  • c. 5 is greater than 9. (F)
  • d. $-13 + 4 = -9$. (T)
📌 Remark:

The collection of all allowable values for the variable in an open sentence is called the universal set (the universe of discourse) and denoted by \(U\).

📌 Definition 1.5:

Two open propositions $P(x)$ and $Q(x)$ are said to be equivalent if and only if $P(a) = Q(a)$ for all individuals $a$ in $U$.

Example 1.12: Let $P(x): x^2 - 1 = 0$ and $Q(x): |x| \geq 1$. Let $U = \{-1, -\frac{1}{2}, 0, 1\}$.

\(a\)\(P(a)\)\(Q(a)\)
$-1$$(-1)^2 - 1 = 0$ (T)$|-1| \geq 1$ (T)
$-\frac{1}{2}$$(-\frac{1}{2})^2 - 1 = 0$ (F)$|-\frac{1}{2}| \geq 1$ (F)
$0$$0 - 1 = 0$ (F)$|0| \geq 1$ (F)
$1$$1^2 - 1 = 0$ (T)$|1| \geq 1$ (T)

Therefore, $P(a) = Q(a)$ for all $a \in U$. Thus, $P(x)$ and $Q(x)$ are equivalent over the given universe $U$.

📌 Definition 1.6:

Let \(U\) be the universal set. An open proposition \(P(x)\) is a tautology if and only if $P(a)$ is always true for all values of \(a \in U\).

Example 1.13: The open proposition $P(x): x^2 \geq 0$ is a tautology (over the real numbers), since the square of any real number is non-negative.

The Three Possibilities of Open Propositions

As we have observed, an open proposition can be converted into a proposition by substituting the individuals for the variables. However, there are other ways that an open proposition can be converted into a proposition, namely by a method called quantification. Let $P(x)$ be an open proposition over the domain $S$. Adding the phrase "For every $x \in S$" to $P(x)$ or "For some $x \in S$" to $P(x)$ produces a statement called a quantified statement.

Consider the following open propositions with universe $\mathbb{R}$:

  • a. $R(x): x^2 \geq 0$ (Always true for each $x \in \mathbb{R}$)
  • b. $P(x): (x + 2)(x - 3) = 0$ (True only for $x = -2$ and $x = 3$)
  • c. $Q(x): x^2 < 0$ (Always false for all values of $x \in \mathbb{R}$)

Hence, given an open proposition $P(x)$ with universe $U$, we observe that there are three possibilities:

  1. $P(x)$ is true for all $x \in U$. (Tautology)
  2. $P(x)$ is true for some $x \in U$. (Satisfiable)
  3. $P(x)$ is false for all $x \in U$. (Unsatisfiable)

Quantifiers

Now we proceed to study open propositions which are satisfied by "all" and "some" members of the given universe.

📌 Universal Quantifier ($\forall$):

The phrase "for every $x$" is called a universal quantifier. We regard "for every $x$", "for all $x$", and "for each $x$" as having the same meaning and symbolize each by $(\forall x)$. Think of the symbol $\forall$ as an inverted A (representing "All"). If $P(x)$ is an open proposition with universe $U$, then $(\forall x)P(x)$ is a quantified proposition and is read as "every $x \in U$ has the property $P$".

📌 Existential Quantifier ($\exists$):

The phrase "there exists an $x$" is called an existential quantifier. We regard "there exists an $x$", "for some $x$", and "for at least one $x$" as having the same meaning and symbolize each by $(\exists x)$. Think of the symbol $\exists$ as the backwards capital E (representing "Exists"). If $P(x)$ is an open proposition with universe $U$, then $(\exists x)P(x)$ is a quantified proposition and is read as "there exists $x \in U$ with the property $P$".

📌 Important Remarks:
  1. To show that $(\forall x)P(x)$ is F, it is sufficient to find at least one $a \in U$ such that $P(a)$ is F. Such an element $a \in U$ is called a counterexample.
  2. $(\exists x)P(x)$ is F if we cannot find any $a \in U$ having the property $P$.

Example 1.14:

a. Write the following statements using quantifiers.

  • i. For each real number $x > 0$, $x^2 + x - 6 = 0$. $\rightarrow$ $(\forall x > 0)(x^2 + x - 6 = 0)$
  • ii. There is a real number $x > 0$ such that $x^2 + x - 6 = 0$. $\rightarrow$ $(\exists x > 0)(x^2 + x - 6 = 0)$
  • iii. The square of any real number is nonnegative. $\rightarrow$ $(\forall x \in \mathbb{R})(x^2 \geq 0)$

b.

  • i. Let $P(x): x^2 + 1 \geq 0$. The truth value for $(\forall x)P(x)$ is T.
  • ii. Let $P(x): x < x^2$. The truth value for $(\forall x)(x < x^2)$ is F. $x = \frac{1}{2}$ is a counterexample since $\frac{1}{2} \in \mathbb{R}$ but $\frac{1}{2} < \frac{1}{4}$.
  • iii. Let $P(x): |x| = -1$. The truth value for $(\exists x)P(x)$ is F since there is no real number whose absolute value is $-1$.

Negation of Quantifiers

Let $P(x)$ be an open proposition. Then $(\forall x)P(x)$ is false only if we can find an individual "a" in the universe such that $P(a)$ is false. If we succeed in getting such an individual, then $(\exists x)\neg P(x)$ is true. Hence, $(\forall x)P(x)$ will be false if $(\exists x)\neg P(x)$ is true.

Therefore, the negation of $(\forall x)P(x)$ is $(\exists x)\neg P(x)$. Similarly, we can easily verify that the negation of $(\exists x)P(x)$ is $(\forall x)\neg P(x)$.

📌 To negate a statement involving quantifiers:

Change each $\forall$ to $\exists$, change each $\exists$ to $\forall$, and negate the open statement.

Example 1.15:

  • a. $\neg(\exists x)(x < x^2) \equiv (\forall x)\neg(x < x^2) \equiv (\forall x)(x \geq x^2)$
  • b. $\neg(\forall x)(4x + 1 = 0) \equiv (\exists x)\neg(4x + 1 = 0) \equiv (\exists x)(4x + 1 \neq 0)$

📌 Cheat Notes: Key Points to Remember (Part 4)

  • Open Proposition (Predicate): A sentence with variables; truth value depends on the variable.
  • Quantifiers: Universal ($\forall$) = "For all"; Existential ($\exists$) = "There exists".
  • Counterexample: One element that makes a universal statement false.
  • Negation Rule: $\forall \rightarrow \exists$, $\exists \rightarrow \forall$, and negate the predicate.
  • Combined Quantifiers: $(\forall x)(\exists y) = y$ depends on $x$; $(\exists y)(\forall x) = y$ must work for all $x$.
