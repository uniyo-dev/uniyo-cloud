1.4. Set theory

The term set is an undefined term, just as a point and a line are undefined terms in geometry. However, the concept of a set permeates every aspect of mathematics. Set theory underlies the language and concepts of modern mathematics.

The term set refers to a well-defined collection of objects that share a certain property or certain properties. The term "well-defined" here means that the set is described in such a way that one can decide whether or not a given object belongs in the set.

If \(A\) is a set, then the objects of the collection \(A\) are called the elements or members of the set \(A\). If \(x\) is an element of the set \(A\), we write \(x \in A\). If \(x\) is not an element of the set \(A\), we write \(x \notin A\).

As a convention, we use capital letters to denote the names of sets and lowercase letters for elements of a set.

Note: For each object \(x\) and each set \(A\), exactly one of \(x \in A\) or \(x \notin A\) (but not both) must be true.

1.4.2. Description of sets

Sets are described or characterized by one of the following four different ways.

MethodDescriptionExample
1. Verbal Method An ordinary English statement describing the property of the elements. "The set of counting numbers less than ten."
2. Roster/Complete Listing Method All elements are listed between braces, separated by commas, without repetition. {1, 2, 3, 4, 6, 8, 12, 24}
3. Partial Listing Method Used when the set has too many elements; list the first few, followed by three dots (...). {1, 2, 3, 4, ...}
4. Set-builder Method Uses an open proposition \(P(x)\) to describe the set: \(A = \{x \mid P(x)\}\). \(\{x \mid x \text{ is an even integer}\}\)

Example 1.23 (Verbal Method):

  • a. The set of counting numbers less than ten.
  • b. The set of letters in the word "Addis Ababa."
  • c. The set of all countries in Africa.

Example 1.24 (Roster Method):

  • a. The set of vowels in the English alphabet: \(\{a, e, i, o, u\}\).
  • b. The set of positive factors of 24: \(\{1, 2, 3, 4, 6, 8, 12, 24\}\).

Example 1.25 (Important Note on Set Elements):

  • a. If \(A = \{a, b, \{c\}\}\), then the elements of \(A\) are \(a\), \(b\), and \(\{c\}\). Notice that \(c\) and \(\{c\}\) are different objects. Here \(\{c\} \in A\) but \(c \notin A\).
  • b. If \(B = \{\{a\}\}\), the only element of \(B\) is \(\{a\}\). But \(a \notin B\).

Example 1.26 (Partial Listing Method):

  • a. The set of all counting numbers: \(\mathbb{N} = \{1, 2, 3, 4, \ldots\}\).
  • b. The set of non-positive integers: \(\{\ldots, -4, -3, -2, -1, 0\}\).

Example 1.27 (Set-builder Method):

  • a. \(A = \{x \mid x \text{ is a vowel in the English alphabet}\}\).
  • b. \(B = \{t \mid t \text{ is an even integer}\}\).
  • c. \(C = \{n \mid n \text{ is a natural number and } 2n - 15 \text{ is negative}\}\).

Relationships Between Sets

DefinitionSymbolMeaning
Empty (Null) Set \(\phi\) or \(\{\}\) The set that has no elements. Example: \(\{x \in \mathbb{R} \mid x^2 + 1 = 0\}\).
Subset \(B \subseteq A\) Every element of \(B\) is an element of \(A\). \((\forall x)(x \in B \Rightarrow x \in A)\).
Proper Subset \(B \subset A\) \(B \subseteq A\) and \(B \neq A\) (i.e., \(A\) has at least one element not in \(B\)).
Equal Sets \(A = B\) They contain exactly the same elements. \((\forall x)(x \in B \Leftrightarrow x \in A)\).
Power Set \(P(A)\) The set of all subsets of \(A\). (\(P(A) = \{B \mid B \subseteq A\}\)).

Example 1.29 (Subsets):

  • If \(A = \{a, b\}\), \(B = \{a, b, c\}\), and \(C = \{a, b, d\}\), then \(A \subseteq B\) and \(A \subseteq C\).
  • If \(S = \{x \mid x \text{ is a multiple of 6}\}\) and \(T = \{x \mid x \text{ is an even integer}\}\), then \(S \subseteq T\) since every multiple of 6 is even.

Example 1.30 (Equal Sets):

The sets \(\{1, 2, 3\}\), \(\{2, 1, 3\}\), and \(\{1, 3, 2\}\) are all equal.

Example 1.31 (Power Set):

Let \(A = \{x, y, z\}\). Then:

\(P(A) = \{\phi, \{x\}, \{y\}, \{z\}, \{x,y\}, \{x,z\}, \{y,z\}, A\}\).

Key Formula: If a set \(A\) has \(n\) elements, its power set \(P(A)\) has exactly \(2^n\) elements.

📌 Cheat Notes: Key Points to Remember (Part 6)

  • Set: A well-defined collection of objects. \(x \in A\) or \(x \notin A\).
  • 4 Description Methods: Verbal, Roster (complete listing), Partial listing, Set-builder.
  • Relationships: Subset (\(\subseteq\)), Proper subset (\(\subset\)), Equal (\(=\)), Empty (\(\phi\)), Power set (\(P(A)\)).
  • Power Set Formula: If \(A\) has \(n\) elements, \(P(A)\) has \(2^n\) elements.
  • Universal Set (\(U\)): The set containing all elements under consideration.
