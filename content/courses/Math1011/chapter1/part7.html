Part 7: Set Operations & Venn Diagrams

📖 MODULE OVERVIEW & LEARNING OBJECTIVES:

Given two subsets \(A\) and \(B\) of a universal set \(U\), new sets can be formed using \(A\) and \(B\) in many ways, such as taking common elements or non-common elements, and putting everything together. Such processes of forming new sets are called set operations. In this final part of Chapter 1, we discuss the three most important operations: union, intersection, and complement, as well as set difference and symmetric difference.

After completing this part, you will be able to:

  • Find the union, intersection, and complement of sets.
  • Find the difference and symmetric difference of sets.
  • Apply the laws of set operations (Commutative, Associative, Distributive, De Morgan's).
  • Illustrate set operations using Venn diagrams.

1.4.3. Set Operations and Venn diagrams

Given two subsets \(A\) and \(B\) of a universal set \(U\), new sets can be formed using \(A\) and \(B\) in many ways, such as taking common elements or non-common elements, and putting everything together. Such processes of forming new sets are called set operations.

OperationSymbolDefinitionLogical Counterpart
Union \(A \cup B\) \(\{x \mid (x \in A) \lor (x \in B)\}\) \(\lor\) (OR)
Intersection \(A \cap B\) \(\{x \mid (x \in A) \land (x \in B)\}\) \(\land\) (AND)
Complement \(A'\) or \(\overline{A}\) \(\{x \mid x \in U \text{ and } x \notin A\}\) \(\neg\) (NOT)
Difference \(A - B\) \(\{x \mid x \in A \text{ and } x \notin B\}\) \(A \cap B'\)
Symmetric Difference \(A \Delta B\) \((A - B) \cup (B - A)\) Elements in exactly one of \(A\) or \(B\).

Example 1.32 (Union and Intersection):

Let \(A = \{0, 1, 3, 5, 6\}\) and \(B = \{1, 2, 3, 4, 6, 7\}\). Then:

\(A \cup B = \{0, 1, 2, 3, 4, 5, 6, 7\}\) and \(A \cap B = \{1, 3, 6\}\).

Example 1.33 (Set Difference):

If \(A = \{1, 3, 5\}\) and \(B = \{1, 2\}\), then \(A - B = \{3, 5\}\) and \(B - A = \{2\}\).

Example 1.35 (Symmetric Difference):

Let \(U = \{1, 2, 3, \dots, 10\}\), \(A = \{2, 4, 6, 8, 9, 10\}\), and \(B = \{3, 5, 7, 9\}\). Then:

\(B - A = \{3, 5, 7\}\) and \(A - B = \{2, 4, 6, 8, 10\}\). Thus:

\(A \Delta B = \{2, 3, 4, 5, 6, 7, 8, 10\}\).

Important Theorems of Set Operations

TheoremDescription
Commutative Laws\(A \cup B = B \cup A\) and \(A \cap B = B \cap A\)
Associative Laws\((A \cup B) \cup C = A \cup (B \cup C)\) and \((A \cap B) \cap C = A \cap (B \cap C)\)
Distributive Laws\(A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\) and \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\)
De Morgan's Laws\((A \cup B)' = A' \cap B'\) and \((A \cap B)' = A' \cup B'\)
Difference Law\(A - B = A \cap B'\)
Double Complement\((A')' = A\)

📌 Cheat Notes: Key Points to Remember (Part 7)

  • Union (\(\cup\)): Elements in \(A\) or \(B\).
  • Intersection (\(\cap\)): Elements in \(A\) and \(B\).
  • Complement (\('\)): Elements in \(U\) but not in \(A\).
  • Difference (\(-\)): Elements in \(A\) but not in \(B\). (\(A - B = A \cap B'\)).
  • Symmetric Difference (\(\Delta\)): \((A - B) \cup (B - A)\).
  • Key Theorems: Commutative, Associative, Distributive, De Morgan's Laws.
  • Venn Diagrams: Visual representation of sets and operations using overlapping circles.
