3.3 Types of Matrices

There are certain types of matrices that are so important that they have acquired names of their own. In this section, we are going to discuss some of these matrices and their properties.

📌 Definition 3.9 (Square Matrix):

A matrix \(A\) is said to be square if it has the same number of rows and columns. If \(A\) has \(n\) rows and \(n\) columns, we call it a square matrix of size \(n\).

📌 Definition 3.10 (Identity Matrix):

A square matrix \(A = [a_{ij}]_{n imes n}\) is called an identity matrix if

\[ a_{ij} = egin{cases} 1 & ext{if } i = j \ 0 & ext{if } i eq j \end{cases} \]

and it is denoted by \(I_n\).

📌 Definition 3.11 (Diagonal Matrix):

A square matrix \(D = [d_{ij}]\) is said to be diagonal if \(d_{ij} = 0\) whenever \(i eq j\). Less formally, \(D\) is said to be diagonal when all the entries off the main diagonal are 0.

📌 Definition 3.12 (Scalar Matrix):

A diagonal matrix in which all diagonal entries are equal is called a scalar matrix.

📌 Definition 3.13 (Triangular Matrix):

A square matrix \(A = [a_{ij}]_{n imes n}\) is said to be lower triangular if and only if \(a_{ij} = 0\) whenever \(i < j\).

\(A\) is said to be upper triangular if and only if \(a_{ij} = 0\) whenever \(i > j\).

Transpose of a Matrix

📌 Definition 3.14 (Transpose):

Let \(A = [a_{ij}]\) be an \(m imes n\) matrix. Then by the transpose of \(A\), we mean the \(n imes m\) matrix, denoted by \(A^t\), whose \((i,j)\)-th entry is the \((j,i)\)-th entry of \(A\). More precisely, if \(A = [a_{ij}]_{m imes n}\), then \(A^t = [a_{ji}]_{n imes m}\).

That is, the \(k\)-th row of matrix \(A\) becomes the \(k\)-th column of \(A^t\), and the \(k\)-th column of \(A\) becomes the \(k\)-th row of \(A^t\).

Example 3.19: Compute the transposes of the following matrices:

\[ A = egin{bmatrix} 1 & 2 & 3 \ 4 & 5 & 6 \end{bmatrix}, \quad B = egin{bmatrix} 1 & 2 \ 3 & 4 \end{bmatrix}, \quad C = egin{bmatrix} 1 & 3 & 5 \end{bmatrix}. \]

Solution:

  • \(A^t = egin{bmatrix} 1 & 4 \ 2 & 5 \ 3 & 6 \end{bmatrix}\) (Row 1 becomes Column 1, Row 2 becomes Column 2).
  • \(B^t = egin{bmatrix} 1 & 3 \ 2 & 4 \end{bmatrix}\).
  • \(C^t = egin{bmatrix} 1 \ 3 \ 5 \end{bmatrix}\).
📌 Definition 3.15 (Symmetric Matrix):

A square matrix \(A\) is said to be symmetric if \(A = A^t\).

Example 3.20: Determine whether the given matrix is symmetric or not.

\(A = egin{bmatrix} 0 & 1 & 3 \ -1 & 0 & 2 \ -3 & -2 & 0 \end{bmatrix}\) is not symmetric because \(A^t = egin{bmatrix} 0 & -1 & -3 \ 1 & 0 & -2 \ 3 & 2 & 0 \end{bmatrix} eq A\).

\(B = egin{bmatrix} 1 & 1 & 3 \ 1 & 2 & 2 \ 3 & 2 & 3 \end{bmatrix}\) is symmetric because \(B^t = B\).

📌 Theorem 3.5 (Properties of Matrix Transpose):

When the relevant sums and products are defined, and \(lpha\) is a scalar:

  1. \((A^t)^t = A\)
  2. \((A + B)^t = A^t + B^t\)
  3. \((lpha A)^t = lpha (A^t)\)
  4. \((AB)^t = B^t A^t\) (Note the reversed order!)

📌 Cheat Notes: Key Points to Remember (Part 3)

  • Square Matrix: Rows = Columns.
  • Identity Matrix (\(I_n\)): 1s on the diagonal, 0s elsewhere.
  • Diagonal Matrix: Non-zero entries only on the main diagonal.
  • Scalar Matrix: A diagonal matrix where all diagonal entries are equal.
  • Triangular Matrix: Upper (zeros below diagonal) or Lower (zeros above diagonal).
  • Transpose (\(A^t\)): Rows become columns, columns become rows.
  • Symmetric Matrix: \(A = A^t\).
  • Transpose Properties: \((AB)^t = B^t A^t\) (Order reverses).
