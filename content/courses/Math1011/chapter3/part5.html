3.7 Determinant and its properties

The determinant is a function that takes a square matrix as input and produces a scalar as output. It has many beneficial properties for studying matrices and systems of equations.

📌 Definition 3.21 (Determinant of \(2 imes 2\) matrix):

The determinant of a \(2 imes 2\) matrix \(A = egin{bmatrix} a & c \ d & b \end{bmatrix}\), denoted by \(\det(A)\) (or \(|A|\)), is defined by the formula:

\[ \det(A) = egin{vmatrix} a & c \ d & b \end{vmatrix} = ab - cd. \]

Minors and Cofactors

The determinant of a \(3 imes 3\) matrix can be defined using the determinants of \(2 imes 2\) matrices. This leads to the concepts of minors and cofactors.

📌 Definition 3.23:

Let \(A = (a_{ij})_{n imes n}\), and let \(A_{ij}\) be the submatrix of \(A\) obtained by deleting the \(i\)-th row and \(j\)-th column of \(A\) for \(i, j = 1, 2, 3, \dots, n\).

  • The minor for \(A\) at location \((i,j)\), denoted by \(M_{ij}(A)\), is the determinant of the submatrix \(A_{ij}\). That is, \(M_{ij}(A) = \det(A_{ij})\).
  • The cofactor, denoted by \(C_{ij}(A)\), for \(A\) at location \((i,j)\) is the signed determinant of the submatrix \(A_{ij}\). That is, \(C_{ij}(A) = (-1)^{i+j} \det(A_{ij})\).

Cofactor Expansion (Laplace Expansion)

📌 Definition 3.24:

The determinant of a square matrix \(A = [a_{ij}]\) of size \(n imes n\), denoted by \(\det(A)\) (or \(|A|\)), is defined recursively. If \(n = 1\), then \(\det(A) = a_{11}\). Otherwise, we use cofactor expansion:

\[ \det(A) = \sum_{k=1}^{n} a_{k1} C_{k1}(A) = a_{11} C_{11}(A) + a_{21} C_{21}(A) + \dots + a_{n1} C_{n1}(A). \]

📌 Theorem 3.7:

The determinant of an \(n imes n\) matrix \(A\) can be computed by cofactor expansion across any row or any column. The value is the same regardless of which row or column is chosen.

Properties of Determinants

Let \(A\) be a square matrix of size \(n\).

PropertyDescription
1. Zero Row/ColumnIf an entire row or column consists of zeros, then \(\det(A) = 0\).
2. Equal Rows/ColumnsIf two rows (or columns) are equal, then \(\det(A) = 0\).
3. Scalar MultipleIf one row (or column) is a scalar multiple of another, then \(\det(A) = 0\).
4. Triangular/DiagonalThe determinant of an upper triangular, lower triangular, or diagonal matrix is the product of the entries on the main diagonal.
5. Transpose\(\det(A) = \det(A^t)\) (Theorem 3.8).

Effects of Elementary Row Operations on Determinants

📌 Theorem 3.9:

Let \(B\) be obtained from a square matrix \(A\) by an elementary row operation.

  1. Interchanging two rows (\(R_i \leftrightarrow R_j\)): \(\det(B) = -\det(A)\).
  2. Multiplying a row by a nonzero scalar (\(R_i o lpha R_i\)): \(\det(B) = lpha \det(A)\).
  3. Adding a multiple of one row to another (\(R_i o R_i + lpha R_j\)): \(\det(B) = \det(A)\) (the determinant is unchanged!).

Why Property (III) is Important: This property is particularly interesting because it doesn't change the determinant. It can be used to transform a matrix into triangular form (upper or lower), for which the determinant is simply the product of the diagonal entries—much easier than direct computation.

Product Rule for Determinants

📌 Theorem 3.10:

If \(A\) and \(B\) are two matrices for which the product \(AB\) is defined, then:

\[ \det(AB) = \det(A) \det(B). \]

📌 Cheat Notes: Key Points to Remember (Part 5)

  • 2×2 Determinant: \(\detegin{bmatrix} a & c \ d & b \end{bmatrix} = ab - cd\).
  • Minor: \(M_{ij}(A) = \det( ext{submatrix after deleting row } i ext{ and column } j)\).
  • Cofactor: \(C_{ij}(A) = (-1)^{i+j} M_{ij}(A)\).
  • Cofactor Expansion: Expand across any row or column. Choose the one with the most zeros!
  • Triangular/Diagonal Determinant: Product of diagonal entries.
  • Row Operations: Interchange → negates; Scale → multiplies; Replacement → no change.
  • Product Rule: \(\det(AB) = \det(A) \det(B)\).
