3.4 Elementary Row Operations

Elementary row operations are useful to find the rank of a matrix, to compute the determinants of matrices, and to find the inverse of a matrix. Furthermore, elementary row operations are widely used in solving systems of linear equations.

In this section, we introduce the elementary row operations and apply these operations to transform the given matrix into different forms.

📌 Definition 3.16:

Let \(A\) be an \(m imes n\) matrix. The following are known as elementary row operations:

  1. Interchanging two rows: \(R_i \leftrightarrow R_j\) (Rule of Interchanging)
  2. Multiplying a row by a nonzero scalar: \(R_i o lpha R_i\), where \(lpha\) is a nonzero scalar (Rule of Scaling)
  3. Adding a multiple of one row to another: \(R_i o R_i + lpha R_j\), where \(lpha\) is a nonzero scalar (Rule of Replacement)

3.5 Row Echelon Form and Reduced Row Echelon Form of a Matrix

In order to find the rank, or to compute the inverse of a matrix, or to solve a linear system, we usually write the matrix either in its row echelon form or reduced row echelon form.

📌 Definition 3.18:

An \(m imes n\) matrix is said to be in row echelon form if the following conditions are satisfied:

  1. All nonzero rows are above any rows of all zeros.
  2. Each leading entry of a row is in a column to the right of the leading entry of the row above it.
  3. All entries in a column below a leading entry are zeros.

If a matrix in row echelon form satisfies the following additional conditions, then it is in reduced row echelon form:

  1. The leading entry in each nonzero row is 1.
  2. Each leading 1 is the only nonzero entry in its column.
📌 Theorem 3.6:

Each matrix is row equivalent to one and only one reduced echelon matrix.

Algorithm to Find the Reduced Row Echelon Form:

  1. Begin with the leftmost nonzero column. This is a pivot column. The pivot position is at the top.
  2. Select a nonzero entry in the pivot column as a pivot. If necessary, interchange rows to move this entry into the pivot position.
  3. Use row replacement operations to create zeros in all positions below the pivot.
  4. Cover (or ignore) the row containing the pivot position and cover all rows, if any, above it. Apply steps 1–3 to the submatrix that remains. Repeat the process until there are no more nonzero rows to modify.
  5. Beginning with the rightmost pivot column and working upward and to the left, create zeros above each pivot. If a pivot is not 1, make it 1 by a scaling operation.

3.6 Rank of a Matrix

The rank of a matrix is useful in determining the number of solutions for linear systems.

📌 Definition 3.20:

The rank of an \(m imes n\) matrix \(A\), denoted by \( ext{rank}(A)\), is the number of nonzero rows of the reduced row echelon form of \(A\).

Remark: The matrix \(A\) and its transpose \(A^t\) have the same rank. That is, \( ext{rank}(A) = ext{rank}(A^t)\).

📌 Cheat Notes: Key Points to Remember (Part 4)

  • Elementary Row Operations: Interchange (\(R_i \leftrightarrow R_j\)), Scale (\(R_i o lpha R_i\)), Replace (\(R_i o R_i + lpha R_j\)).
  • Row Echelon Form: Nonzero rows above zero rows, leading entries step to the right, zeros below leading entries.
  • Reduced Row Echelon Form: Row echelon form + leading entries are 1 + zeros above and below each leading 1.
  • Uniqueness: Every matrix has a unique reduced row echelon form.
  • Rank: The number of nonzero rows in the reduced row echelon form.
  • Rank Property: \( ext{rank}(A) = ext{rank}(A^t)\).
