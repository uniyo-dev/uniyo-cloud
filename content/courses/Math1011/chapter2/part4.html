Chapter 2: Functions

Part 4: Operations on Functions & Composition

📖 MODULE OVERVIEW & LEARNING OBJECTIVES:

In this part, we learn how to perform arithmetic operations on functions: addition, subtraction, multiplication, and division. We also explore composition of functions, a powerful way to combine two functions by using the output of one as the input of another.

After completing this part, you will be able to:

  • Perform the four fundamental operations on functions.
  • Determine the domain of the sum, difference, product, and quotient of two functions.
  • Compose functions to get a new function.
  • Define equality of two functions.

2.4 Real Valued functions and their properties

Let \(f\) be a function from set \(A\) to set \(B\). If \(B\) is a subset of the real number system \(\mathbb{R}\), then \(f\) is called a real-valued function. In particular, if \(A\) is also a subset of \(\mathbb{R}\), then \(f: A \to B\) is called a real function.

Example 2.24: The function \(f: \mathbb{R} \to \mathbb{R}\) defined by \(f(x) = x^2 + 3x + 7\) is a real function. The function \(f(x) = |x|\) is also a real-valued function.

Operations on Functions

Functions are not numbers. But just as two numbers \(a\) and \(b\) can be added to produce a new number \(a + b\), so two functions \(f\) and \(g\) can be added to produce a new function \(f + g\). This is just one of several operations on functions that we will describe in this section.

Consider functions \(f\) and \(g\) with formulas \(f(x) = \frac{x-3}{2}\) and \(g(x) = \sqrt{x}\). We can make a new function \(f + g\) by having it assign to \(x\) the value \(\frac{x-3}{2} + \sqrt{x}\). That is, \((f + g)(x) = f(x) + g(x)\).

📌 Definition 2.9: Sum, Difference, Product, and Quotient of Two Functions

Let \(f(x)\) and \(g(x)\) be two functions. We define the following four functions:

  1. Sum: \((f + g)(x) = f(x) + g(x)\)
  2. Difference: \((f - g)(x) = f(x) - g(x)\)
  3. Product: \((f \cdot g)(x) = f(x)g(x)\)
  4. Quotient: \(\left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}\) (provided \(g(x) \neq 0\))

Domain Rules for Function Operations:

  • Since an \(x\)-value must be an input into both \(f\) and \(g\), the domain of \((f + g)(x)\) is the set of all \(x\) common to the domain of \(f\) and \(g\): \(Dom(f + g) = Dom(f) \cap Dom(g)\).
  • The same rule applies to the difference and product of two functions.
  • For the quotient, we must impose the additional restriction that all elements in the domain of \(g\) for which \(g(x) = 0\) are excluded.

Example 2.25: Let \(f(x) = 3x^2 + 2\) and \(g(x) = 5x - 4\).

  • \((f + g)(x) = 3x^2 + 5x - 2\)
  • \((f - g)(x) = 3x^2 - 5x + 6\)
  • \((f \cdot g)(x) = 15x^3 - 12x^2 + 10x - 8\)
  • \(\left(\frac{f}{g}\right)(x) = \frac{3x^2 + 2}{5x - 4}\)

Domains: \(Dom(f+g) = Dom(f-g) = Dom(fg) = \mathbb{R}\). \(Dom(f/g) = \mathbb{R} \setminus \{\frac{5}{4}\}\).

Composition of Functions

There is yet another way of producing a new function from two given functions.

📌 Definition 2.10: Composition of Functions

Given two functions \(f(x)\) and \(g(x)\), the composition of the two functions is denoted by \(f \circ g\) and is defined by:

\[(f \circ g)(x) = f[g(x)].\]

\((f \circ g)(x)\) is read as "\(f\) composed with \(g\) of \(x\)".

Domain of Composition: The domain of \(f \circ g\) consists of those \(x\)'s in the domain of \(g\) whose range values are in the domain of \(f\). That is, those \(x\)'s for which \(g(x)\) is in the domain of \(f\).

Example 2.26: Suppose \(f = \{(2,z),(3,q)\}\) and \(g = \{(a,2),(b,3),(c,5)\}\).

  • \((f \circ g)(a) = f(g(a)) = f(2) = z\)
  • \((f \circ g)(b) = f(g(b)) = f(3) = q\)
  • \((f \circ g)(c) = f(g(c)) = f(5)\) is undefined because 5 is not in the domain of \(f\).

Thus, \(f \circ g = \{(a,z),(b,q)\}\).

Example 2.27: Given \(f(x) = 5x^2 - 3x + 2\) and \(g(x) = 4x + 3\).

  • \((f \circ g)(x) = f(4x + 3) = 5(4x + 3)^2 - 3(4x + 3) + 2 = 80x^2 + 108x + 38\).
  • \((g \circ f)(x) = g(5x^2 - 3x + 2) = 4(5x^2 - 3x + 2) + 3 = 20x^2 - 12x + 11\).

Note: In general, \(f \circ g \neq g \circ f\).

Equality of Functions

📌 Definition 2.11: Equality of Functions

Two functions are said to be equal if and only if the following two conditions hold:

  1. The functions have the same domain.
  2. Their functional values are equal at each element of the domain.

Example 2.28:

  • \(f(n) = n^2\) and \(g(n) = |n|^2\) for all \(n \in \mathbb{Z}\) are equal because \(Dom(f) = Dom(g) = \mathbb{Z}\) and \(f(n) = g(n)\) for all \(n\).
  • \(f(x) = \frac{x^2 - 25}{x - 5}\) (domain \(\mathbb{R} \setminus \{5\}\)) and \(g(x) = x + 5\) (domain \(\mathbb{R}\)) are not equal because their domains are different.

📌 Cheat Notes: Key Points to Remember (Part 4)

  • Operations on Functions: Sum \((f+g)\), Difference \((f-g)\), Product \((fg)\), Quotient \((f/g)\).
  • Domain of Operations: Sum/Difference/Product: \(Dom(f) \cap Dom(g)\). Quotient: \(Dom(f) \cap Dom(g) \setminus \{x \mid g(x) = 0\}\).
  • Composition: \((f \circ g)(x) = f(g(x))\). Domain: \(x \in Dom(g)\) such that \(g(x) \in Dom(f)\).
  • Equality of Functions: Same domain AND same values at every point in the domain.
  • Note: In general, \(f \circ g \neq g \circ f\).
