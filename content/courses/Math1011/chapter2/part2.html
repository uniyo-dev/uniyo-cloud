2.2 Equations and Inequalities: Linear and Quadratic

An equation is a symbolic statement of equality. For example, rather than writing "twice a number is four less than the number," we write \(2x = x - 4\). Our goal is to find the solution to a given equation—the value or values of the variable that make the algebraic statement true.

Linear Equations

📌 Definition 2.1:

A linear equation in one variable is an equation that can be put in the form \(ax + b = 0\), where \(a\) and \(b\) are constants, and \(a \neq 0\).

Equivalent Equations: Equations that have the same solutions are called equivalent equations. For example, \(3x - 1 = 5\) and \(3x = 6\) are equivalent because the solution set of both is \(\{2\}\).

Properties for Solving Equations:

  • Addition Property: If \(a = b\), then \(a + c = b + c\).
  • Multiplication Property: If \(a = b\), then \(ac = bc\) (for \(c \neq 0\)).

📐 Worked Example 2.2:

Solve for \(x\): \(820x = 10x + 30(50 - x)\)

Step 1: Simplify the right-hand side by distributing and combining like terms.

\[820x = 10x + 1500 - 30x\]

\[820x = 1500 - 20x\]

Step 2: Apply the addition property. Add \(20x\) to both sides to gather variable terms.

\[840x = 1500\]

Step 3: Apply the multiplication property. Divide both sides by 840.

\[x = \frac{1500}{840} = \frac{25}{14}\]

Step 4: Always check your work by substituting \(x = \frac{25}{14}\) back into the original equation.

💼 Real-World Example 2.5 (Ethiopian Business Context):

Problem: A man has a daughter and a son. The man is five times older than his daughter. Moreover, his age is twice the sum of the ages of his daughter and son. His daughter is 3 years younger than his son. How old is the man and his children?

Step 1: Define variables.

  • Let \(m\) = age of the man.
  • Let \(d\) = age of the daughter.
  • Let \(s\) = age of the son.

Step 2: Translate the word problem into equations.

  • "The man is five times older than his daughter" \(\rightarrow m = 5d\)
  • "His age is twice the sum of the ages of his daughter and son" \(\rightarrow m = 2(d + s)\)
  • "His daughter is 3 years younger than his son" \(\rightarrow d = s - 3 \implies s = d + 3\)

Step 3: Solve the system.

Substitute \(s = d + 3\) into the second equation: \(m = 2(d + d + 3) \implies m = 4d + 6\).

Equate the two expressions for \(m\): \(5d = 4d + 6 \implies d = 6\).

Then \(s = d + 3 = 9\), and \(m = 5d = 30\).

Answer: The man is 30, his daughter is 6, and his son is 9.

Special Cases: Identities and Contradictions

  • Identity: An equation that is true for all real numbers. Example: \(5x - 2(x - 1) + 4 = 3(x + 2)\). Simplifying gives \(6 = 6\), so the solution set is \(\mathbb{R}\) (all real numbers).
  • Contradiction: An equation that is true for no real numbers. Example: \(x + 10 = x\). Simplifying gives \(10 = 0\), which is false. The solution set is \(\emptyset\) (the empty set).

Linear Inequalities

📌 Definition 2.2:

A linear inequality is an inequality that can be put in the form \(ax + b < 0\), where \(a\) and \(b\) are constants with \(a \neq 0\). (The \(<\) symbol can be replaced with \(>\), \(\leq\), or \(\geq\).)

Properties for Solving Inequalities:

  • \(a < b \implies a + c < b + c\)
  • If \(c > 0\), \(a < b \implies ac < bc\)
  • 🔴 CRITICAL RULE: If \(c < 0\), \(a < b \implies ac > bc\) (reverse the inequality symbol!)

📐 Worked Example 2.6:

Solve: \(5x + 8(20 - x) \geq 2(x - 5)\).

\(5x + 160 - 8x \geq 2x - 10\)

\(160 - 3x \geq 2x - 10\)

\(-5x \geq -170\)

Divide by \(-5\) (REVERSE THE INEQUALITY):

\(x \leq 34\).

Solution Set: \(\{x \in \mathbb{R} \mid x \leq 34\} = (-\infty, 34]\).

Domain Restrictions: Sometimes a solution must belong to a specified domain. For example, solving \(x - 4(x + 1) \geq -13 - (x - 2)\) in the set of natural numbers (\(\mathbb{N}\)) gives \(x \leq 3.5\), so the solution set in \(\mathbb{N}\) is \(\{1, 2, 3\}\). If no solution exists in the specified domain, the solution set is \(\emptyset\).

Quadratic Equations

A quadratic equation is a polynomial equation in which the highest degree of the variable is 2. The standard form is \(Ax^2 + Bx + C = 0\), where \(A \neq 0\). The solutions are also called the roots of the equation.

Methods for Solving Quadratic Equations:

MethodWhen to UseExample
Factoring When the polynomial is easily factorable. \(x^2 + x - 6 = 0 \implies (x-2)(x+3)=0 \implies x=2, -3\)
Square Root Theorem When the equation is in the form \(x^2 = d\). \(5x^2 = 14 \implies x = \pm\sqrt{\frac{14}{5}}\)
Completing the Square Always works, but is algebraically intensive. Best for deriving the quadratic formula. \(x^2 - 4x = 1 \implies (x-2)^2 = 5 \implies x = 2 \pm \sqrt{5}\)
Quadratic Formula ALWAYS works. The universal method. \(x = \frac{-B \pm \sqrt{B^2 - 4AC}}{2A}\)

📐 Quadratic Formula Worked Example:

Solve: \(x^2 - 8 = -6x\).

Step 1: Rewrite in standard form: \(x^2 + 6x - 8 = 0\).

Step 2: Identify \(A=1, B=6, C=-8\).

Step 3: Apply the Quadratic Formula.

\[x = \frac{-6 \pm \sqrt{6^2 - 4(1)(-8)}}{2(1)} = \frac{-6 \pm \sqrt{68}}{2} = -3 \pm \sqrt{17}\]

Solution Set: \(\left\{-3 - \sqrt{17}, -3 + \sqrt{17}\right\}\).

Quadratic Inequalities

A quadratic inequality is in standard form if it is written as \(Ax^2 + Bx + C < 0\) (replace \(<\) with \(>\), \(\leq\), or \(\geq\)).

The Sign Analysis Method:

  1. Write the inequality in standard form.
  2. Find the cut points (the roots of the corresponding quadratic equation). These split the number line into intervals.
  3. Test the sign of the expression in each interval.
  4. Determine the solution set based on where the sign satisfies the inequality.

📐 Worked Example 2.14 (Sign Analysis):

Solve: \(x^2 - 2x - 2 < 0\).

Step 1: Find the cut points using the Quadratic Formula.

\[x = \frac{2 \pm \sqrt{4 - 4(1)(-2)}}{2} = \frac{2 \pm \sqrt{12}}{2} = 1 \pm \sqrt{3}.\]

The cut points are \(1 - \sqrt{3} \approx -0.7\) and \(1 + \sqrt{3} \approx 2.7\).

Step 2: Test points in the intervals \((-\infty, 1-\sqrt{3})\), \((1-\sqrt{3}, 1+\sqrt{3})\), and \((1+\sqrt{3}, \infty)\).

Step 3: The expression is negative only in the middle interval.

Solution Set: \((1 - \sqrt{3}, 1 + \sqrt{3})\).

📌 Cheat Notes: Key Points to Remember

  • Linear Equations: Isolate the variable using addition/multiplication properties.
  • Linear Inequalities: Reverse the inequality symbol when multiplying or dividing by a negative number.
  • Quadratic Formula: \(x = \frac{-B \pm \sqrt{B^2 - 4AC}}{2A}\). Memorize it. It always works.
  • Cut Points: The roots of the quadratic equation. They split the number line for sign analysis.
  • Domain Restrictions: Always check if the solution belongs to the specified domain (e.g., \(\mathbb{N}\), \(\mathbb{W}\), \(\mathbb{Q}\)). If not, the solution set is \(\emptyset\).
