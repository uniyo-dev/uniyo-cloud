Chapter 2: Functions

Part 3: Relations and Functions, Domain & Range

📖 MODULE OVERVIEW & LEARNING OBJECTIVES:

In this part, we define the Cartesian product of sets, which leads to the formal definition of a relation. We then distinguish relations from functions, which are special relations that assign exactly one output to each input. We also explore the domain, codomain, and range of relations and functions.

After completing this part, you will be able to:

  • Define the Cartesian product of two sets.
  • Understand the notion of a relation and its inverse.
  • Determine the domain and range of relations and functions.
  • Distinguish between a relation and a function.

2.3. Review of relations and functions

The student is familiar with the phrase ordered pair. In the ordered pairs \((2,3)\), \((-2,4)\), and \((a,b)\), 2, -2, and \(a\) are the first coordinates, while 3, 4, and \(b\) are the second coordinates.

Cartesian Product

Given sets \(A = \{3,4\}\) and \(B = \{4,5,9\}\). Then the set \(\{(3,4),(3,5),(3,9),(4,4),(4,5),(4,9)\}\) is the Cartesian product of \(A\) and \(B\), and it is denoted by \(A \times B\).

📌 Definition 2.3:

Suppose \(A\) and \(B\) are sets. The Cartesian product of \(A\) and \(B\), denoted by \(A \times B\), is the set which contains every ordered pair whose first coordinate is an element of \(A\) and second coordinate is an element of \(B\). That is,

\[A \times B = \{(a,b) \mid a \in A \text{ and } b \in B\}.\]

Example 2.15: For \(A = \{2,4\}\) and \(B = \{-1,3\}\), we have:

\(A \times B = \{(2,-1),(2,3),(4,-1),(4,3)\}\) and \(B \times A = \{(-1,2),(-1,4),(3,2),(3,4)\}\).

From this example, we can see that \(A \times B\) and \(B \times A\) are not equal.

📌 Definition 2.4:

Two ordered pairs \((a,b)\) and \((c,d)\) are equal if and only if \(a = c\) and \(b = d\).

Relations

📌 Definition 2.5:

If \(A\) and \(B\) are sets, any subset of \(A \times B\) is called a relation from \(A\) into \(B\).

If \((a,b) \in R\), we say \(a\) is related to \(b\), and write \(aRb\). If \((a,b) \notin R\), we say \(a\) is not related to \(b\). In particular, if \(R\) is a relation from a set \(A\) to itself, then we say that \(R\) is a relation on \(A\).

📌 Definition 2.6:

Let \(R\) be a relation from \(A\) into \(B\).

  • The domain of \(R\), denoted by \(Dom(R)\), is the set of first coordinates of the elements of \(R\): \(Dom(R) = \{a \in A \mid (a,b) \in R\}\).
  • The range of \(R\), denoted by \(Range(R)\), is the set of second coordinates of elements of \(R\): \(Range(R) = \{b \in B \mid (a,b) \in R\}\).
  • The set \(B\) is called the codomain of the relation \(R\). The range is always a subset of the codomain.

Example 2.18: The set \(R = \{(4,7),(5,8),(6,10)\}\) is a relation from \(A = \{1,2,3,4,5,6\}\) to \(B = \{6,7,8,9,10\}\).

\(Dom(R) = \{4,5,6\}\), \(Range(R) = \{7,8,10\}\), and \(Codomain(R) = \{6,7,8,9,10\}\).

Inverse Relation: If \(R\) is a relation from \(A\) to \(B\), then the inverse relation of \(R\), denoted by \(R^{-1}\), is a relation from \(B\) to \(A\) defined as:

\[R^{-1} = \{(y,x) \mid (x,y) \in R\}.\]

Observe that \(Dom(R) = Range(R^{-1})\) and \(Range(R) = Dom(R^{-1})\).

Functions

Mathematically, it is important for us to distinguish among the relations that assign a unique range element to each domain element and those that do not.

📌 Definition 2.7:

A function is a relation in which each element of the domain corresponds to exactly one element of the range.

Example 2.21: Determine whether the following relations are functions.

  • \(R = \{(5,-2),(3,5),(3,7)\}\): Not a function because domain element 3 is assigned to two different values (5 and 7).
  • \(\{(2,4),(3,4),(6,-4)\}\): Is a function because each domain element is assigned no more than one value.

Remark: Map, mapping, transformation, and correspondence are synonyms for the word function. If \(f\) is a function and \((x,y) \in f\), we say \(x\) is mapped to \(y\).

📌 Definition 2.8:

A relation \(f\) from \(A\) into \(B\) is called a function from \(A\) into \(B\), denoted by \(f: A \to B\) or \(A \xrightarrow{f} B\), if and only if:

  1. \(Dom(f) = A\) (every element of \(A\) is used as an input), and
  2. No element of \(A\) is mapped by \(f\) to more than one element in \(B\) (i.e., if \((x,y) \in f\) and \((x,z) \in f\), then \(y = z\)).

Notation: If \(f(x) = y\), then \(y\) is called the image of \(x\) under \(f\), and \(x\) is called a pre-image of \(y\). The symbol \(f(x)\) is read as "\(f\) of \(x\)" (not "\(f\) times \(x\)").

Functions Defined by Equations: Just like relations, we can describe a function with an equation. For example, \(y = 2x + 1\) is a function, since each \(x\) will produce only one \(y\).

Example 2.23 (Domain, Codomain, and Range):

  • If \(A = \{1,2,3\}\), \(B = \{1,2,3,\dots,10\}\), and \(f(x) = x^2\), then \(Dom(f) = \{1,2,3\}\), \(Range(f) = \{1,4,9\}\), and the codomain is \(B\).
  • If \(f(x) = \frac{2x}{3x-5}\), then the domain is all real numbers except \(\frac{5}{3}\) (where the denominator is zero).
  • If \(y = \sqrt{3x - x^2}\), then the domain is found by solving \(3x - x^2 \geq 0\), which gives \(0 \leq x \leq 3\).

📌 Cheat Notes: Key Points to Remember (Part 3)

  • Cartesian Product: \(A \times B = \{(a,b) \mid a \in A, b \in B\}\). Order matters!
  • Relation: Any subset of \(A \times B\).
  • Function: A relation where each input maps to exactly one output.
  • Domain: Set of all inputs (first coordinates).
  • Range: Set of all outputs (second coordinates).
  • Codomain: The set \(B\) in \(f: A \to B\). The range is always a subset of the codomain.
  • Inverse Relation: \(R^{-1} = \{(y,x) \mid (x,y) \in R\}\).
