Chapter 2: Functions

Part 5: Types of Functions & Inverse Functions

📖 MODULE OVERVIEW & LEARNING OBJECTIVES:

In this part, we study three important types of functions: One-to-One, Onto, and One-to-One Correspondence. We then explore the concept of inverse functions, which exist only for one-to-one functions.

After completing this part, you will be able to:

  • Define one-to-one, onto, and one-to-one correspondence.
  • Check invertibility of a function.
  • Find the inverse of an invertible function.

2.5 Types of functions

In this section, we shall study some important types of functions.

One-to-One Functions

📌 Definition 2.12:

A function \(f: A \to B\) is called one-to-one (often written \(1-1\)), if and only if for all \(x_1, x_2 \in A\), \(f(x_1) = f(x_2)\) implies \(x_1 = x_2\). In words, no two elements of \(A\) are mapped to the same element of \(B\).

Example 2.28: Let \(A = \{1,2,3,4,5,6\}\) and \(B = \{7,a,b,c,d,8,e\}\).

  • \(f = \{(1,7),(2,a),(3,b),(4,b),(5,c),(6,8)\}\) is not one-to-one because \(f(3) = f(4)\) but \(3 \neq 4\).
  • \(g = \{(1,7),(2,a),(3,b),(4,c),(5,8),(6,d)\}\) is one-to-one.

Onto Functions

📌 Definition 2.13:

Let \(f\) be a function from a set \(A\) into a set \(B\). Then \(f\) is called an onto function (or \(f\) maps onto \(B\)) if every element of \(B\) is the image of some element in \(A\). That is, \(\text{Range}(f) = B\).

Example 2.29:

  • \(A = \{1,2,3\}\), \(B = \{1,4,5\}\). \(f(1)=1, f(2)=5, f(3)=1\) is not onto because 4 has no preimage.
  • \(g = \{(1,4),(2,5),(3,1)\}\) is onto because every element of \(B\) has a preimage.

Identity Map: If \(A\) is a non-empty set, the function \(i_A: A \to A\) defined by \(i_A(x) = x\) for all \(x \in A\) is a one-to-one function from \(A\) onto \(A\). \(i_A\) is called the identity map on \(A\).

Example 2.30:

  • \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = n^2\) is not one-to-one (\(f(1)=f(-1)\)) and not onto (negative integers have no preimage).
  • \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = 2n\) is one-to-one (\(f(n)=f(n') \Rightarrow n=n'\)) but not onto (odd integers have no preimage).

One-to-One Correspondence

📌 Definition 2.14:

A function \(f: A \to B\) is said to be a one-to-one correspondence if \(f\) is both one-to-one and onto.

Example 2.31: Let \(A = \{0,1,2,3,4,5\}\) and \(B = \{0,5,10,15,20,25\}\). The function \(f(x) = 5x\) is a one-to-one correspondence between \(A\) and \(B\).

Theorem: If \(A\) is a finite set and \(f: A \to A\) is onto, then it is one-to-one.

Inverse of a Function

Since a function is a relation, the inverse of a function \(f\) is denoted by \(f^{-1}\) and is defined by:

\[f^{-1} = \{(y,x) \mid (x,y) \in f\}\]

Important Fact: The inverse of a function is not always a function. For example, \(f = \{(2,4),(3,6),(5,4)\}\) has inverse \(f^{-1} = \{(4,2),(6,3),(4,5)\}\), which is not a function because 4 maps to both 2 and 5.

Key Rule: A function has an inverse if and only if it is one-to-one.

Steps to Find the Inverse of a One-to-One Function:

  1. Interchange \(x\) and \(y\) in the equation \(y = f(x)\).
  2. Solve the resulting equation for \(y\) to obtain the inverse function.

Important Note: The domain of the inverse function is the range of the original function, and the range of the inverse function is the domain of the original function.

Example 2.31: Find the inverse of \(f(x) = x^3\).

\(y = x^3 \Rightarrow x = y^3 \Rightarrow y = \sqrt[3]{x}\). Thus, \(f^{-1}(x) = \sqrt[3]{x}\).

Example 2.32: Find the inverse of \(f(x) = \frac{x}{x+2}\).

\(y = \frac{x}{x+2} \Rightarrow x = \frac{y}{y+2} \Rightarrow xy + 2x = y \Rightarrow y(1-x) = 2x \Rightarrow y = \frac{2x}{1-x}\).

Thus, \(f^{-1}(x) = \frac{2x}{1-x}\).

📌 Crucial Warning:

In general, a negative exponent indicates a reciprocal. However, inverse function notation is an exception. Please be aware that:

\[f^{-1}(x) \neq \frac{1}{f(x)}\]

If you want to write the reciprocal of \(f(x)\) using a negative exponent, you must write \(\frac{1}{f(x)} = [f(x)]^{-1}\).

📌 Cheat Notes: Key Points to Remember (Part 5)

  • One-to-One (1-1): Each input maps to a unique output. \(f(x_1) = f(x_2) \Rightarrow x_1 = x_2\).
  • Onto: Every element of the codomain is used. \(Range(f) = B\).
  • One-to-One Correspondence: Both 1-1 and onto.
  • Inverse Function: Exists if and only if the function is one-to-one.
  • To find the inverse: Interchange \(x\) and \(y\), then solve for \(y\).
  • Domain/Range of Inverse: \(Dom(f^{-1}) = Range(f)\) and \(Range(f^{-1}) = Dom(f)\).
  • ⚠️ Warning: \(f^{-1}(x) \neq \frac{1}{f(x)}\).
