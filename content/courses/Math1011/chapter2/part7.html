2.7 Definition and basic properties of logarithmic, exponential, and trigonometric functions and their graphs

Exponents and Radicals

📌 Definition 2.16:

For a natural number \(n\) and a real number \(x\), the power \(x^n\) is defined as \(x^n = \underbrace{x \cdot x \cdots x}_{n \text{ factors}}\).

In the symbol \(x^n\), \(x\) is called the base and \(n\) is called the exponent.

We extend the definition to include zero and negative exponents:

RuleFormulaCondition
Zero Exponent\(x^0 = 1\)\(x \neq 0\)
Negative Exponent\(x^{-n} = \frac{1}{x^n}\)\(x \neq 0\)
Rational Exponent\(x^{\frac{m}{n}} = (\sqrt[n]{x})^m\)\(x^{\frac{1}{n}}\) is real

Rules for Integer Exponents:

  • \(x^n \cdot x^m = x^{n+m}\)
  • \((x^n)^m = x^{nm}\)
  • \(\left(\frac{x}{y}\right)^n = \frac{x^n}{y^n}\) (\(y \neq 0\))

Exponential Functions

📌 Definition 2.21:

A function of the form \(y = f(x) = b^x\), where \(b > 0\) and \(b \neq 1\), is called an exponential function.

PropertyDescription
DomainAll real numbers (\(\mathbb{R}\))
RangePositive real numbers \((0, \infty)\)
y-intercept\(1\) (since \(b^0 = 1\))
Horizontal Asymptote\(y = 0\) (the x-axis)
One-to-One\(b^{x_1} = b^{x_2} \Rightarrow x_1 = x_2\)
Growth/DecayGrowth if \(b > 1\); Decay if \(0 < b < 1\)

Example 2.45: Sketch \(y = 2^x\). It passes through \((-3, 1/8), (-2, 1/4), (-1, 1/2), (0, 1), (1, 2), (2, 4), (3, 8)\).

Logarithmic Functions

📌 Definition 2.22:

For \(b > 0\) and \(b \neq 1\), \(y = \log_b x\) means \(y\) is the exponent to which \(b\) must be raised to yield \(x\).

\[x = b^y \Leftrightarrow y = \log_b x\]

Exponential FormLogarithmic Form
\(4^2 = 16\)\(\log_4 16 = 2\)
\(5^{-3} = 1/125\)\(\log_5 (1/125) = -3\)
\(7^0 = 1\)\(\log_7 1 = 0\)
📌 Important Logarithmic Properties:

For \(b, u, v > 0, b \neq 1\):

  • \(\log_b(uv) = \log_b u + \log_b v\) (Product Rule)
  • \(\log_b\left(\frac{u}{v}\right) = \log_b u - \log_b v\) (Quotient Rule)
  • \(\log_b(u^r) = r \log_b u\) (Power Rule)
  • \(\log_b(b^x) = x\)
  • \(b^{\log_b x} = x\)

Common and Natural Logarithms:

  • Common Logarithm: \(\log_{10} x = \log x\)
  • Natural Logarithm: \(\log_e x = \ln x\) (where \(e \approx 2.7182\dots\))

Trigonometric Functions

Angle Measurement:

An angle is formed by two rays with a common endpoint. The fixed side is the initial side, and the rotating side is the terminal side. Angles are measured in degrees or radians.

Conversion Formula: \(\frac{\theta \text{ in degrees}}{180^\circ} = \frac{\theta \text{ in radians}}{\pi}\).

DegreesRadians
\(180^\circ\)\(\pi\)
\(90^\circ\)\(\frac{\pi}{2}\)
\(60^\circ\)\(\frac{\pi}{3}\)
\(45^\circ\)\(\frac{\pi}{4}\)
\(30^\circ\)\(\frac{\pi}{6}\)

Trigonometric Functions Definitions: For an angle \(\theta\) in standard position with point \(P(x,y)\) on the terminal side and \(r = \sqrt{x^2 + y^2}\):

  • \(\sin \theta = \frac{y}{r}\), \(\cos \theta = \frac{x}{r}\), \(\tan \theta = \frac{y}{x}\)
  • \(\csc \theta = \frac{r}{y}\), \(\sec \theta = \frac{r}{x}\), \(\cot \theta = \frac{x}{y}\)

Periodic Functions: A function \(f(x)\) is periodic if \(f(x+p) = f(x)\) for some \(p\). The smallest such \(p\) is the period. The amplitude is \(A = \frac{1}{2}(\max f - \min f)\).

FunctionDomainPeriod
\(\sin x, \cos x\)All real numbers\(2\pi\)
\(\tan x, \sec x\)\(x \neq \frac{\pi}{2} + n\pi\)\(\pi\)
\(\csc x, \cot x\)\(x \neq n\pi\)\(2\pi\)

📌 Cheat Notes: Key Points to Remember (Part 7)

  • Exponential Functions: \(y = b^x\) (\(b > 0, b \neq 1\)). Domain: \(\mathbb{R}\), Range: \((0, \infty)\).
  • Logarithmic Functions: \(y = \log_b x\) is the inverse of \(y = b^x\). Domain: \((0, \infty)\), Range: \(\mathbb{R}\).
  • Logarithmic Properties: Product, Quotient, Power Rules.
  • Trigonometric Functions: Defined on the unit circle. Periods: \(\sin, \cos = 2\pi\); \(\tan = \pi\).
  • Identities: \(\sin^2 x + \cos^2 x = 1\), \(\tan^2 x + 1 = \sec^2 x\).
